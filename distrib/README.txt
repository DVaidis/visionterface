VISIONTERFACE - unofficial open source standalone client for Visio (visio.numerique.gouv.fr)
Client autonome open source non officiel pour Visio
D. C. Vaidis - MIT licence - coded with Claude (Anthropic, Opus 5.5)
https://github.com/DVaidis/visionterface

=== ENGLISH ===
INSTALL
1. Right-click the zip > Extract All.
2. In the extracted folder, double-click Install.bat
   (current user only, no administrator rights; shortcut on the Desktop and in the Start menu).
3. First launch: Windows may show "Windows protected your PC" (unsigned app):
   click "More info" > "Run anyway".
USE
- Paste a Visio meeting link or code (e.g. abc-defg-hij) in the top bar, press Enter.
- Joined meetings go to "Recent"; "Name" saves them to "Favourites".
- Your sign-in is kept between launches. FR / EN button at the bottom left.
UNINSTALL
- Double-click Uninstall.bat (in the extracted folder or in %LOCALAPPDATA%\Programs\Visionterface).
Your links stay on your PC (%APPDATA%\Visionterface). Nothing is sent elsewhere.
Not affiliated with DINUM.

=== FRANCAIS ===
INSTALLER
1. Clic droit sur le zip > Extraire tout.
2. Dans le dossier extrait, double-cliquer Install.bat
   (pour votre compte uniquement, sans droits administrateur ; raccourci Bureau + menu Demarrer).
3. Premier lancement : "Windows a protege votre ordinateur" (application non signee) :
   "Informations complementaires" > "Executer quand meme".
UTILISER
- Coller un lien de reunion Visio ou un code (ex. abc-defg-hij) dans la barre du haut, Entree.
- Les reunions rejointes vont dans "Recents" ; "Nommer" les range dans "Favoris".
- La connexion est conservee d'un lancement a l'autre. Bouton FR / EN en bas a gauche.
DESINSTALLER
- Double-cliquer Uninstall.bat (dossier extrait ou %LOCALAPPDATA%\Programs\Visionterface).
Vos liens restent sur votre PC (%APPDATA%\Visionterface). Rien n'est envoye ailleurs.
Application non affiliee a la DINUM.
